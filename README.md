# Mebel — маркетплейс мебели в Ташкенте

Площадка, где покупатель находит мебельщика, а мебельщик — клиентов.
Готовая мебель и мебель на заказ: кухни, спальни и гостиные, офисная, детская.

## Как всё устроено

Три части, которые работают вместе:

| Часть | Что делает | Сервис |
|---|---|---|
| **Код** | Файлы сайта | GitHub |
| **Сайт** | Показывает страницы людям | Cloudflare Workers |
| **Данные** | Продавцы, товары, фото, регистрация | Supabase |

Схема работы: код лежит в GitHub → Cloudflare забирает его и публикует сайт →
сайт берёт данные из Supabase.

## Страницы

| Адрес | Что это |
|---|---|
| `/` | Главная: поиск, категории, выбор «готовая / на заказ» |
| `/catalog` | Каталог с фильтрами: категория, тип, район |
| `/companies` | Список всех мебельщиков города |
| `/company/[slug]` | Профиль мастера: работы, телефон, соцсети |
| `/product/[id]` | Карточка мебели: фото, цена, кнопка звонка |

Все страницы рендерятся на сервере — так они попадают в поиск Google.
Это главный источник бесплатного трафика для маркетплейса.

## Как заработать (заложено в базу)

1. **Платная подписка** для продавцов — таблица `subscriptions` (планы free / standard / premium).
2. **Платное продвижение** — таблица `promotions`: поднятие объявления на N часов,
   оплаченный товар поднимается в каталоге выше остальных.

Приём оплаты: Payme или Click — подключаются отдельным этапом.

## Настройка базы (один раз)

1. Открой панель Supabase → **SQL Editor**.
2. Скопируй туда содержимое `supabase/migrations/0001_marketplace.sql` и запусти.

Что создаст миграция: поля профиля компании, категории каталога, таблицу продвижения,
правила доступа (чтобы каждый продавец правил только своё), хранилище для фото
и автосоздание профиля при регистрации.

## Запуск на своём компьютере

```bash
npm install
cp .env.example .env.local   # вписать свои ключи Supabase
npm run dev                  # откроется на http://localhost:3000
```

Ключи берутся в Supabase → **Project Settings → API**.

## Публикация на Cloudflare

```bash
npm run cf:preview   # посмотреть локально, как будет работать на Cloudflare
npm run cf:deploy    # опубликовать
```

Либо подключить репозиторий к Cloudflare Workers через веб-панель — тогда сайт
будет обновляться сам при каждом изменении кода.

В настройках Cloudflare нужно добавить те же две переменные, что и в `.env.local`:
`NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
