# Mebel — маркетплейс мебели в Ташкенте

Площадка, где покупатель находит мебельщика, а мебельщик — клиентов.
Готовая мебель и мебель на заказ: кухни, спальни и гостиные, офисная, детская.

## Как всё устроено

Три части, которые работают вместе:

| Часть | Что делает | Сервис |
|---|---|---|
| **Код** | Файлы сайта | GitHub |
| **Сайт** | Показывает страницы людям | Cloudflare Workers |
| **Данные** | Продавцы, товары, фото, регистрация | Supabase |

Схема работы: код лежит в GitHub → Cloudflare забирает его и публикует сайт →
сайт берёт данные из Supabase.

## Страницы

| Адрес | Что это |
|---|---|
| `/` | Главная: поиск, категории, выбор «готовая / на заказ» |
| `/catalog` | Каталог с фильтрами: категория, тип, район |
| `/companies` | Список всех мебельщиков города |
| `/company/[slug]` | Профиль мастера: работы, телефон, соцсети |
| `/product/[id]` | Карточка мебели: фото, цена, кнопка звонка |

Все страницы рендерятся на сервере — так они попадают в поиск Google.
Это главный источник бесплатного трафика для маркетплейса.

## Как заработать (заложено в базу)

1. **Платная подписка** для продавцов — таблица `subscriptions` (планы free / standard / premium).
2. **Платное продвижение** — таблица `promotions`: поднятие объявления на N часов,
   оплаченный товар поднимается в каталоге выше остальных.

Приём оплаты: Payme или Click — подключаются отдельным этапом.

## Что уже работает

**Покупатель:** ищет мебель в каталоге, фильтрует по категории, типу и району,
смотрит страницу мастера, звонит напрямую или оставляет заявку.

**Мастер:** регистрируется, заполняет профиль мастерской, добавляет мебель с фото,
получает заявки в кабинет и в Telegram, ведёт клиентов и заказы по этапам,
заказывает продвижение.

**Площадка:** админ проверяет новые мастерские, блокирует недобросовестных,
подтверждает оплату продвижения.

## Настройка базы (один раз)

Миграции лежат в `supabase/migrations/`. Применяются в панели Supabase →
**SQL Editor** → вставить содержимое файла → **Run**, по порядку номеров.

Что настраивают: профили мастерских, категории каталога, товары с фото,
CRM (клиенты и заказы), продвижение, приём заявок с защитой от спама
и правила доступа — каждый мастер видит только свои данные.

### Стать администратором площадки

Зарегистрируйтесь на сайте, затем в **SQL Editor**:

```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = 'ваша@почта');
```

После этого откроется раздел `/admin`.

## Запуск на своём компьютере

```bash
npm install
cp .env.example .env.local   # вписать свои ключи Supabase
npm run dev                  # откроется на http://localhost:3000
```

Ключи берутся в Supabase → **Project Settings → API**.

## Публикация на Cloudflare Workers

Подключение репозитория один раз — дальше сайт обновляется сам при каждом
изменении кода.

1. **dash.cloudflare.com** → **Compute (Workers)** → **Create**
2. Вкладка **Import a repository** → выбрать `mebel-marketplace`
3. Настройки сборки:
   - **Build command:** `npm run cf:build`
   - **Deploy command:** `npx wrangler deploy`
   - **Git branch:** `main`
4. **Build variables and secrets** — обязательно, иначе сборка упадёт:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. После первой сборки: **Settings → Variables & Secrets** — те же две переменные
   плюс `TELEGRAM_BOT_TOKEN`, если нужны уведомления о заявках.

Локальная проверка того же самого: `npm run cf:preview`, публикация вручную:
`npm run cf:deploy`.

## Уведомления в Telegram

Мастер получает заявку в Telegram, если у мастерской заполнен `telegram_chat_id`,
а в переменных окружения задан `TELEGRAM_BOT_TOKEN` (токен от @BotFather).
Без этого заявки всё равно сохраняются и видны в кабинете.
